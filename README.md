# roccos-assets

Images for Rocco's Pizza (Phoenixville, PA): the command center tablet and the Framer website.

Served free through jsDelivr:

    https://cdn.jsdelivr.net/gh/BCooney2026/roccos-assets@main/soups/<file>

## soups/

| File | Soup |
| --- | --- |
| soup-italian-wedding.webp | Italian Wedding |
| soup-chicken-noodle.webp | Chicken Noodle |
| soup-stuffed-pepper.webp | Stuffed Pepper |
| soup-cheesesteak.webp | Philly Cheesesteak |
| soup-minestrone.webp | Minestrone |
| soup-pasta-fagioli.webp | Pasta Fagioli |

800x800 WebP. To add a soup: drop the photo in soups/, then add a row to the Soups tab in the Rocco's Command Center Sheet with the file name in the Photo column.

If you replace a photo with the same file name, jsDelivr can keep the old one for up to 12 hours. Use a new file name instead (for example soup-minestrone-2.webp) and update the Sheet.
